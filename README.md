# Pencatatan-Produk-Toko

Aplikasi desktop berbasis **JavaFX** yang dirancang untuk mengelola inventaris toko secara efisien. Aplikasi ini menerapkan arsitektur *Model-View-Controller* (MVC) dengan antarmuka modern.

## Fitur Utama
- **Form Input Produk (`form.fxml`):** Menambahkan data produk baru lengkap dengan validasi input, pilihan kategori (Makanan/Minuman), harga, stok, serta unggah foto produk.
- **Daftar Produk (`daftar.fxml`):** Tabel interaktif untuk menampilkan seluruh daftar produk dengan thumbnail gambar, fitur pencarian kode/nama, filter kategori, serta pengelolaan data (lihat detail dan hapus).
- **Detail Produk (`detail.fxml`):** Halaman khusus yang menampilkan informasi mendetail dari produk terpilih, termasuk format mata uang Rupiah dan tampilan gambar produk yang jelas.

## Cara Menjalankan Aplikasi

Karena konfigurasi project dan struktur *build* sudah diatur sebelumnya, Anda dapat langsung menjalankan aplikasi ini dengan langkah berikut:

1. Buka aplikasi **Apache NetBeans** (atau IDE pilihan Anda yang mendukung JavaFX).
2. Buka project **Pencatatan Produk Toko** melalui menu `File` -> `Open Project...`.
3. Lakukan **Clean and Build** pada project untuk memastikan seluruh file FXML dan *dependencies* terkompilasi dengan baik.
4. Jalankan aplikasi menggunakan tombol **Run** atau tekan shortcut **`Shift + F6`** pada keyboard Anda.
